## 一、总体目标

以最低成本搭建可运行的 MVP 闭环：**课程学习 → 风险测评 → 深度接洽 → 社区分享 → 电台预警 → 后台审核**，三端（H5 / API / Admin）可构建、可运行、可演示。

## 四、关键技术决策

1. **数据库默认 SQLite，生产 MySQL**：同一 Prisma schema 通过 `DB_PROVIDER` 切换，规避方言差异（不使用原生 enum、不依赖 MySQL 专属类型），保证本地零依赖可运行。
2. **AI 双引擎**：`DEEPSEEK_API_KEY` 配置后走大模型（输出结构化 JSON，含提示词版本），否则回退本地风险词库规则引擎，确保演示与离线可用。
3. **视频轻运营**：H5 不承载视频文件，仅存外链（后台校验白名单域名），跳转抖音/视频号播放。
4. **鉴权双体系**：用户端 `/api/*` 与管理端 `/admin/*` 使用不同 JWT secret（`JWT_SECRET` 与 `JWT_SECRET:admin`），互不串用。
5. **强制匿名**：社区互动一律匿名昵称，不可关闭；`ANONYMOUS_NICKNAME_PREFIX` 随机生成。

## 五、合规红线（贯穿开发）

- 测评输出"风险特征/风险等级"，不做"骗子"等定性判断；报告附免责声明。
- 课程页显著标注"不承诺任何收益，个体效果差异极大"。
- 不推荐具体金融产品；高风险信号触发紧急提示（12315 / 110）。
- 图片打码（MVP 以文案提示为主，OCR 自动打码列入后续迭代）。
